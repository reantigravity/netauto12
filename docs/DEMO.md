## Если спросят «что такое…»
- **Dual-stack** — на каждом интерфейсе одновременно IPv4 и IPv6.
- **Source of truth** (`network.yaml`) — единственное место, где описано, какой должна быть сеть.
- **Compliance validation** — автоматическая сверка реального состояния сети с планом.
- **Jinja2** — шаблонизатор: из плана и шаблона получается готовый конфиг Cisco.
- **Netmiko** — Python-библиотека для подключения к сетевым устройствам по SSH.
- **NETCONF/YANG** — протокол и модель данных для настройки устройств через XML вместо CLI.
